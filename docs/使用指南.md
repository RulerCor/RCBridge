# RCBridge 使用指南

## 连接与运行

1. 在 Windows x64 安装 WebView2 Runtime，完整解压便携包并打开 `RCBridge.exe`。
2. 在 WeRC 复制「Bot 接入」配置，在 RCBridge 导入；填写下游 OneBot v11 的反向 WebSocket 地址和可选令牌。
3. 保存后重新打开 RCBridge，点击「启动桥接」并确认两端已连接。用测试联系人验证实际收发。

通用模式不需要 AstrBot。需要编辑私聊白名单或管理员时，在「其他接入与端口」填写 AstrBot 的 `data/cmd_config.json` 路径；保存权限后重启 AstrBot。本地文件发送还需配置附件目录。

## 群聊与排查

- 「刷新名单」会读取 WeRC 联系人快照及最近的原生观测；这是已知群，不是完整通讯录。没有显示名时会显示群标识。找不到某个群时，让群成员发一条新消息，再刷新。
- 缺少群名时，在 WeRC 的本地联系人页面打开「导出通讯录」，选 JSON 和「群聊」，再在 RCBridge 点「导入群名」。请用同一微信账号；只保存群名与群标识，OneBot 群 ID 不变。
- 群回复开关立即生效。刷新只识别群，不会把旧消息转发给机器人。
- 收不到消息：确认 WeRC 已连接微信、Bot 授权含 `messages:read` 且账号一致，再检查 OneBot 连接和群回复开关。联系人名称需要快照与 `contacts:read`。
- 发不出去：看运行日志和 WeRC 发件箱。排队或待批准不等于已送达；结果未知时先查回执，不要盲目重发。
- Alpha、WeFlow 与 Windows UIA 是可选兼容路径，不等同于 WeRC。[Alpha 接入说明](Alpha接入说明.md)

## 数据与构建

便携包的用户资料默认在 `%LOCALAPPDATA%\RCBridge`，也可用 `RCBRIDGE_HOME` 指向独立资料目录。升级时保留资料目录，只替换整套程序。不要分享配置中的授权令牌或日志。

构建命令见 [README](../README.md#从源码构建--build-from-source)，发版见[版号与存档](版号与存档.md)。
